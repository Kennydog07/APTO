# UK small-space home-organisation store — automation system

A largely automated UK dropshipping business on Shopify with self-hosted n8n, built for a UK-resident sole trader.

> **Status (12 Oct 2026): built and tested in test mode. No eligibility blockers remain.** Before going live you need to set up Shopify Payments, complete the policies, choose your trader address, register for Self Assessment and pay the ICO fee. See [`LEGAL-AND-PAYMENTS-CHECKLIST.md`](LEGAL-AND-PAYMENTS-CHECKLIST.md) and [`LAUNCH-CHECKLIST.md`](LAUNCH-CHECKLIST.md).

## What's here
| Folder / file | Contents |
|---|---|
| `ops-service/` | Node 22 integration service: verified Shopify webhooks, idempotent order routing, pricing & profit engine, **product scoring engine**, supplier adapters, inventory/price monitors, tracking, support automation, returns, marketing approval queue, reports, AI spend cap, encrypted backups, **owner dashboard**. 67 tests |
| `shopify-theme/` | Online Store 2.0 theme (brand "Nook & Order", provisional): all required pages, mobile-first, accessible, structured data, no fake reviews or urgency |
| `n8n-workflows/` | 14 importable workflows (generated by `tools/build-n8n-workflows.mjs` from `config.json`) |
| `deploy/` | Docker Compose (Caddy HTTPS + n8n + ops-service), hardening, backup and restore scripts |
| `PRODUCT-SHORTLIST.csv` | 14 candidates with computed maximum viable landed cost. Supplier data **to be verified** |
| `product-data/pricing-dashboard.html` | Pricing dashboard (open in a browser) |
| `marketing/` | 30-day calendar, Pinterest playbook, video scripts, email sequences, SEO copy |
| `docs/policies/` | UK policy drafts (terms, privacy, cookies, delivery, returns, refunds, contact, complaints) |
| `docs/brand/` | Three brand identities with conflict checks |
| `tests/` | Theme preview harness (Playwright) and the n8n end-to-end test |

## Quick commands
```bash
cd ops-service && npm install
npm test                         # 67 tests
npm run score-products           # score PRODUCT-SHORTLIST.csv
npm run pricing-report -- ../PRODUCT-SHORTLIST.csv ../product-data/pricing-dashboard.html
npm run hash-password            # dashboard password hash for .env
npm start                        # local test-mode server → http://localhost:8080/dashboard
node ../tools/build-n8n-workflows.mjs   # regenerate workflows after editing n8n-workflows/config.json
```

## Safety defaults
Test mode on · supplier orders over £75 or £300/day need approval · refunds never automatic · products, large price changes and marketing need approval · four emergency pause switches · AI capped at £15/month · nothing purchased, published or registered without the owner's approval.
