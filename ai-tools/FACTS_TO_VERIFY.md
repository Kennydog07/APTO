# Facts to verify

Every legal, financial or safety fact the batch 2 tools rely on. They are **static config in code** (never written by the AI), so if a rule changes, the code must change.

**Re-check every 6 months** (next due: **May 2027**). For each row: open the source, confirm the fact, then update the file in `shared/rules/`, the `*_CHECKED` date constant at its top, the "Checked" date here, and run `npm test`. Blog posts that quote a fact are listed in the last column.

All facts below were checked against the linked page on the date shown.
